# Northgrain LinkedIn extension

This directory contains the internal Chrome extension. Production packages are
generated by the CRM build with the public API URL and application version
embedded in the archive.

Chrome: download the Chrome package, unzip it, open `chrome://extensions`, enable
Developer mode, and choose Load unpacked.

Open the extension from the browser toolbar once, enter a `crm:write` API token,
and use Save and test connection. The same popup shows every pending capture and
reports when an extension update is required.

On a LinkedIn profile, use Review in Northgrain beside the profile actions or
Review current profile from the toolbar. The extension extracts only visible
details and adds a review draft to its Chrome-local queue.

When you accept a LinkedIn invitation, the extension persists the relationship
before forwarding the click to LinkedIn. It enriches drafts one at a time in an
inactive profile tab, then presents review dialogs in capture order. Closing a
review keeps it for later unless it is explicitly discarded.

Saving a review writes it to a durable outbox. Network failures retry
automatically, and the draft is removed only after the CRM confirms the write.
The API canonicalizes the LinkedIn profile URL so replaying a capture updates the
same contact and does not create duplicate follow-up tasks.

The extension never sends LinkedIn messages.
